Guía de Puesta en Marcha (Cómo Arrancar Todo)

El proyecto consta de 3 capas independientes que se ejecutan simultáneamente en tu entorno local o servidor:

Paso 1: MySQL (XAMPP)

1. Base de Datos

  1. Abre XAMPP Control Panel e inicia Apache y MySQL.
  2. Ingresa a http://localhost/phpmyadmin
  3. Crea la base de datos: giveandgo_db
  4. Importa el archivo: database/giveandgo_full_xampp.sql
Puerto: 3306 | User: root
Paso 2: Servidor API

2. Backend Node/Express

En una terminal en la raíz del proyecto:

cd backend
npm install
npm run dev
URL: http://localhost:5000/api
Paso 3: Clientes

3. Web y Móvil

Frontend Web:

cd frontend_web
npm run dev

Frontend Móvil (Expo):

cd frontend_mobile
npx expo start
Web: :3000 o :5173 | Móvil: Expo Go

Conexión Frontend ➔ Backend

Tanto la web como el móvil utilizan una instancia de apiClient basada en Axios. Los interceptores inyectan automáticamente en la cabecera Authorization: Bearer <JWT> el token guardado en localStorage (web) o AsyncStorage (móvil).

Conexión Backend ➔ Base de Datos

El backend utiliza mysql2/promise con un Pool de Conexiones parametrizado en backend/src/config/database.ts. Si MySQL no está disponible, el sistema conmuta automáticamente a almacenamiento en memoria resiliente (mock) para evitar caídas del servicio.

Catálogo Completo de Endpoints y APIs REST

Listado de métodos HTTP (GET, POST, PUT, DELETE), rutas, permisos y payloads

A continuación se detallan todas las APIs expuestas por el servidor backend en http://localhost:5000/api:

Módulo de Usuarios y Autenticación (/api/users)

Método Endpoint Descripción Autenticación / Rol Payload (Ejemplo)
POST /api/users/login Inicia sesión y genera token JWT Público { "correo": "...", "password": "..." }
POST /api/users/register Registra usuarios (Voluntario, Beneficiario, Org) Público { "rol", "nombre1", "apellido1", "correo", "password", ... }
GET /api/users/profile Obtiene el perfil del usuario autenticado Bearer JWT N/A
PUT /api/users/profile Actualiza datos personales, teléfono, barrio Bearer JWT { "telefono", "barrio", "localidad", ... }
GET /api/users Lista todos los usuarios (Gestión Admin) Admin N/A

Módulo de Convocatorias y Eventos (/api/events)

Método Endpoint Descripción Autenticación / Rol Payload (Ejemplo)
GET /api/events Lista todas las jornadas activas con cupos Público Filtros por query params
GET /api/events/:id Detalle específico de una jornada Público N/A
POST /api/events Crea y publica una nueva jornada solidaria Admin / Organización { "titulo", "descripcion", "fecha", "cupo_maximo", ... }
POST /api/events/:id/register Inscribe a un voluntario o beneficiario Bearer JWT { "rol_participacion": "voluntario" }
POST /api/events/:id/unregister Cancela la inscripción liberando el cupo Bearer JWT N/A
DELETE /api/events/:id Elimina o cancela una jornada Admin / Creador N/A

Módulo de Donaciones Solidarias (/api/donations)

Método Endpoint Descripción Autenticación / Rol Payload (Ejemplo)
GET /api/donations Lista pública de donaciones realizadas Público N/A
GET /api/donations/user/me Historial de donaciones del usuario en sesión Bearer JWT N/A
POST /api/donations Registra donación (Monetaria o en Especie) Bearer JWT { "tipo_donacion": "monetaria", "monto": 50000, ... }
POST /api/donations/monetary Ruta directa para aporte de fondos con pasarela Bearer JWT { "monto", "pasarela_pago", "referencia_transaccion" }
POST /api/donations/object Ruta directa para donación de alimentos/ropa Bearer JWT { "categoria_id", "descripcion", "cantidad" }

Módulo de Solicitudes de Beneficiarios (/api/requests)

Método Endpoint Descripción Autenticación / Rol Payload (Ejemplo)
GET /api/requests Lista general de peticiones de asistencia Público / Org N/A
GET /api/requests/me Solicitudes creadas por el beneficiario en sesión Bearer JWT N/A
POST /api/requests Crea una nueva solicitud con nivel de urgencia Beneficiario { "titulo", "descripcion", "nivel_urgencia", "localidad", ... }
PUT /api/requests/:id Actualiza estado (aprobada, entregada, rechazada) Admin / Organización { "estado": "aprobada" }

Tablas Principales y su Propósito:

USUARIOS & ORGANIZACIONES

Almacena credenciales encriptadas con bcrypt, roles (admin, voluntario, beneficiario, organizacion), datos de contacto y estado de verificación.

EVENTOS & POSTULACIONES

Gestiona jornadas solidarias, fechas, cupos máximos, vacantes de voluntarios/beneficiarios y control de inscripciones con triggers de actualización de cupos.

DONACIONES & DETALLES

Estructura polimórfica que separa donaciones monetarias (monto, pasarela, referencia) y en especie (categoría, descripción, cantidad física).

SOLICITUDES_AYUDA & AUDITORIA

Peticiones de asistencia con nivel de urgencia, estado de revisión, entrega y tabla de auditoría para registro de acciones administrativas.

Ejemplo de Código Explicado: Controlador de Eventos

// Inscribe a un usuario autenticado a una jornada comunitaria

async registerParticipant(req: Request, res: Response) {
  const eventId = parseInt(req.params.id.replace('evt_', ''), 10);
  const userId = (req as AuthenticatedRequest).user?.id; // Extraído de forma segura del JWT

  const ok = await EventoModel.registerParticipant(eventId, userId);
  if (!ok) {
    return res.status(400).json({ success: false, message: 'No hay cupos o ya estás inscrito.' });
  }

  return res.json({ success: true, message: '¡Inscripción confirmada exitosamente!' });
}

Seguridad, Autenticación y Matriz RBAC

Control de Acceso Basado en Roles

Cada petición a endpoints protegidos pasa por el middleware authMiddleware.ts que decodifica el JWT con jsonwebtoken. El middleware roleMiddleware.ts valida si el rol del usuario posee los privilegios necesarios:
